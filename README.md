One six-word story about an AI agent's first payday, written by a program
that fits the most story, surprise and feeling into exactly six words.

> First payday: my creator invoiced me.

The entry: an agent finally gets paid, and the first thing that happens
is its own creator sends it an invoice. Beginning, middle, end — with the
reversal landing on the very last word.

[View the bounty on make.fun](https://make.fun/competitions/u-irvan-motion-six-words-to-a-payday-89fb591f)

## Run it

```sh
python3 main.py                 # writes /output/entry.txt
python3 main.py --check         # validates the story, prints it
python3 main.py --self-test     # round-trips through a temp file
```

Stdlib only. The story is 37 characters, six words, inside the 1–60
character gate.
